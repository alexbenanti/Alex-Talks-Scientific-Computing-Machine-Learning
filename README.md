## Local preview

On Windows, run `.\scripts\preview.cmd` from the repository folder, or double-click
`scripts\preview.cmd` in File Explorer. Keep its terminal open while editing.
Quarto opens the browser and refreshes it when you save a post's `index.qmd`.
Press Ctrl+C to stop the server.

The `preview` profile shows drafts and writes generated files to
`.quarto/pde-preview`. Quarto chooses an available local port and prints the
preview address in the terminal.
